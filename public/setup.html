StockX — preparar a base de dados

Este passo cria as tabelas, categorias e segurança no seu Supabase. Faz-se uma única vez.

  1. Carregue no botão verde Copiar SQL aqui em baixo.
  2. No Supabase, no menu da esquerda, abra SQL Editor.
  3. Carregue em New query, clique na área branca e cole (Ctrl+V).
  4. Carregue em Run (ou Ctrl+Enter).
  5. Deve aparecer Success. Pronto! Avise-me e eu ligo o site.
